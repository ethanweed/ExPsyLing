Small Coding Project Ideas

Based on skills covered in this course: variables, loops, conditionals, functions

Easy (-ish, but still good)

  • Mad Libs generator — Ask the user for a few words (a noun, a verb, an adjective...) and plug them into a silly story template.
  • Temperature converter — Let the user type a temperature and convert it between Celsius and Fahrenheit, as many times as they want.
  • Simple calculator — Ask for two numbers and an operation (add, subtract, etc.) and print the result.
  • Number guessing game — The computer picks a secret number and the player keeps guessing, getting a "too high" or "too low" hint each time.
  • FizzBuzz — Count up through a range of numbers, printing "Fizz" for multiples of 3, "Buzz" for multiples of 5, and "FizzBuzz" for both.
  • Grade assigner — Ask for a test score and print the matching letter grade.
  • Rock-paper-scissors — Play a round against the computer, which picks randomly.
  • Password strength checker — Look at a password someone typed and tell them if it's weak or strong based on its length and the kinds of characters in it.
  • Multiplication table printer — Print out the times table for a number the user picks.
  • Leap year checker — Ask for a year and say whether it's a leap year.

Medium (I kinda like this coding stuff, I think)

  • Simple quiz game — Store a handful of questions and answers, ask them one by one, and keep score of how many the player gets right.
  • Countdown timer / stopwatch — Count down from a chosen number of seconds, or time how long something takes.
  • Palindrome checker — Check whether a word or phrase reads the same backwards as forwards.
  • Caesar cipher encoder/decoder — Scramble a message by shifting each letter a set number of places in the alphabet, and write the matching program to unscramble it.
  • Dice roll simulator — Roll a virtual die many times and show how often each number came up.
  • Word counter — Take a sentence and report how many words it has and how often each letter appears.
  • Simple to-do list — A little menu-driven program where the user can add tasks, remove them, and see the current list.

Harder (I have a feeling coding might just be for me)

  • Hangman game — The classic word-guessing game, where the player loses a chance each time they guess a wrong letter.
  • Caesar cipher breaker — Take a scrambled message and have the program try every possible shift until it finds one that makes sense.

Pre-NLP projects (good preparation for Computational Linguistics next semester!)

  • Word frequency counter — Take a chunk of text (e.g. a page of text, or a novel from project gutenberg) and find out which words show up most often.
  • Vowel/consonant counter — Go through a sentence and count how many vowels versus consonants it contains.
  • Simple tokenizer — Write a function that takes a piece of text and breaks it up into a list of separate words. The function could also return the number of words
  • Average word length calculator — Work out the average number of letters per word in a piece of text.
  • Case normalizer + cleaner — Write a function to prepare text for NLP analysis: make everything lowercase and strip out punctuation.
  • Letter frequency histogram — Count how often each letter appears in a text and print a simple bar chart made of text characters.
  • Simple text search — Count how many times a particular word appears in a paragraph.
